# 개발 기록

퇴직연금 인출 최적화 계산기를 만들면서 내린 결정과, 그 과정에서 틀렸던 것들을 남긴다.

이 프로젝트의 어려움은 화면이나 인프라가 아니라 **도메인**에 있다.
연금 세법은 매년 바뀌고, 숫자 하나가 틀리면 사용자가 잘못된 판단을 하게 된다.
그래서 기록의 대부분도 "무엇을 근거로 이 숫자를 썼는가"에 관한 것이다.

---

## 이 프로젝트를 한 문장으로

> 퇴직연금·연금저축을 **언제 얼마씩 인출해야 세금이 가장 적은지** 계산해 주는 공개 웹 서비스.
> 세율·한도는 코드에 박지 않고 법령 원문에서 끌어와 데이터로 관리한다.

## 로드맵

- **Phase 0** ✅ 뼈대 + 세법 명세서 + 단년도 계산 엔진 + 테스트
- **Phase 1** 입력 화면 + 결과 리포트 → 배포
- **Phase 2** 다년도 시뮬레이션 (55→90세 배분 최적화)
- **Phase 3** 해설 콘텐츠 + SEO
- **Phase 4** 회원 + 시나리오 저장
- **Phase 5** 전 연금 통합 관리 / 포트폴리오 제안
