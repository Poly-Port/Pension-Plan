# 퇴직연금 인출 최적화 계산기

퇴직연금·연금저축을 **언제 얼마씩 인출해야 세금이 가장 적은지** 계산해 주는 웹 서비스입니다.

인출 방식에 따라 세금이 수백만 원 달라지지만, 대부분의 사람은 그 사실을 모릅니다.
연 1,500만 원 분리과세 경계, 연금수령연차별 감면율, 연령별 세율 같은 규칙을 대신 계산해
최적의 인출 계획을 알려줍니다.

> ⚠️ 이 계산기의 결과는 **참고용 추정치이며 세무 자문이 아닙니다.**
> 실제 신고·납부는 세무 전문가 또는 국세청 확인을 거치시기 바랍니다.

---

## 이 프로젝트가 신경 쓰는 것

### 입력한 정보가 서버로 가지 않습니다

나이·소득·재산은 한 사람의 재산 상태를 거의 그대로 드러냅니다.
**세금 계산은 전부 브라우저 안에서 이루어지며, 입력값은 서버로 전송되지 않습니다.**
받지 않은 데이터는 유출될 수 없습니다. → [ADR 0002](docs/portfolio/decisions/0002-계산은-브라우저에서.md)

### 모든 숫자에 근거가 있습니다

세율·한도·공제액은 **법령 원문**에서 가져옵니다. 증권사나 블로그 자료는 근거로 쓰지 않습니다.
인용한 조문의 원문은 공포일·시행일·취득일과 함께 [`docs/sources/`](docs/sources/)에 보관하고 있어,
"이 숫자가 왜 이 값인가"를 조문 단위로 추적할 수 있습니다.
→ [ADR 0004](docs/portfolio/decisions/0004-법령원문을-저장소에.md)

### 세법이 바뀌어도 코드를 고치지 않습니다

세율은 코드에 박지 않고 `src/lib/rules/<연도>.json` 에만 둡니다.
개정되면 JSON 파일만 교체하면 됩니다. → [ADR 0003](docs/portfolio/decisions/0003-세법규칙을-데이터로.md)

## 기술 스택

| 영역 | 사용 기술 |
|---|---|
| 프레임워크 | Next.js 16 (App Router) · React 19 · TypeScript |
| 스타일 | Tailwind CSS 4 |
| 테스트 | Vitest |
| 계산 엔진 | 순수 TypeScript (React·DOM 의존 없음) |
| 근거 수집 | 법제처 국가법령정보 공동활용 OPEN API |

## 구조

```
docs/
  tax-rules-2026.md      세법 규칙 명세서 — 엔진의 모든 숫자에 대한 근거
  sources/               법령 조문 원문 (API로 수집, 시행일·취득일 기록)
  portfolio/             설계 결정(ADR) · 트러블슈팅 · 개발 일지
src/
  lib/rules/2026.json    세법 규칙 데이터 (연도별)
  lib/tax/               계산 엔진
    types.ts               입출력 타입
    rules.ts               규칙 로더
    severance.ts           퇴직소득세 원천 계산
    withdrawal.ts          연간 인출 계산
    tax.test.ts            테스트 30개
  app/                   화면
scripts/
  fetch-law.mjs          법령 조문 원문 수집 스크립트
```

## 시작하기

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # 계산 엔진 테스트
npm run build    # 프로덕션 빌드
```

법령 원문을 다시 수집하려면:

```bash
node scripts/fetch-law.mjs --law 소득세법 --jo 129 --save
```
